# Publication

**GingkoMaracino: Tiny Virus, Big Prospects** — 9th Annual SEA-PHAGES
Symposium abstract (2017), Rockland Community College.

Jakubowicz E., Hughes C., Peeples C., Reveil S.M., Schifano V.,
**Twumasi-Ankrah R.**, Waters R., McLean J.

The abstract presents the genome annotation and comparative analysis of
*Mycobacteriophage GingkoMaracino* — the phage whose complete genome
(GenBank MK359341.1) ships as example data in `../data/`. Key findings
include an endolysin system exclusive to cluster A phages, phage
attachment sites homologous to *M. tuberculosis* bacterial attachment
sites, and an exonuclease with potential use in engineering knockouts
and point mutations in *M. tuberculosis*.
